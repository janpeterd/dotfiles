The dependency explorer uses Graph.select to return a stable subgraph. Its two indexes are built from immutable edge records when a Graph is constructed. Graphs may contain cycles, shared descendants and several named bindings between the same nodes.

Add `max_depth: int | None = None` to select. Depth is the minimum hop distance from any root using the selected direction. None is unlimited; zero selects only roots. Negative values, booleans and non-integers raise ValueError. Unknown roots and directions remain errors even when max_depth is zero. Empty roots return an empty selection. Nodes and edges remain sorted and deduplicated by their full identity. Return all original edges whose endpoints are both selected, including cycle-closing edges and differently named bindings. Calls on the same Graph must remain independent. Keep construction and existing select calls compatible.
