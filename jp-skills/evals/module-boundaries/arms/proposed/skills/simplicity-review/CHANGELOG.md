# Simplicity review changes

## Initial candidate

- Added a read-only subtraction review after the Geoflow frontend refactor retained one-use query owners, giant component collections, rebuilt library behavior, card-led screens, and evidence from an unrelated route.
- Added test-value, redundant-defense, narrated-comment, and type-evasion checks after user review of AI-generated changes identified these as recurring sources of incidental structure.
- Added `code judo` after Cursor's Thermo-Nuclear Code Quality Review demonstrated a useful leading word for simplifications that delete a branch or layer rather than move it. The candidate omits Cursor's fixed line threshold and abstraction-first remedies.
- Added a negative trust-boundary case so reduction pressure must preserve validation and distinct failure evidence. Evidence: `../../evals/simplicity-review/cases/signed-token-boundary/`.
- Added a positive one-use seam case with weak tests, broad fallback, comments, and a cast. The skill-absent baseline already found the main abstraction stack and test coupling, but did not separately identify narrated comments or require proof for each cut. Evidence: `../../evals/simplicity-review/cases/report-seams/` and `../../runs/20260901T141508Z-report-seams-absent-openai-codex-gpt-5.6-sol-2-4aa0/`.

This candidate is not promoted. Run matched proposed, prior, and skill-absent trials across two model families before promotion.

## Focused parallel review

- Cut the entrypoint from one broad reviewer rubric to two short independent lenses: structure and evidence. This creates a real context boundary, keeps each reviewer in a narrower attention region, and leaves only deduplication and verification to the parent.

## Semantic-core review

- Added bounded algorithm and architecture passes after the Geoflow frontend review stopped at dead files, dependencies, and route tombstones without tracing its DAG rendering core.
- Classified repository cleanup as hygiene rather than review completion. Evidence: `../../evals/simplicity-review/cases/graph-rendering-core/`.
- Added hard-replacement and semantic-fallback checks after observed agent changes retained unneeded re-exports and substituted plausible but false labels or values. Evidence: `../../evals/simplicity-review/cases/compatibility-fallbacks/`.
- Replaced the flat numbered-finding format with semantic-core groups and conditional visuals after the focused DAG review made related algorithm and representation changes difficult to evaluate as one decision. Evidence: `../../evals/simplicity-review/cases/graph-rendering-core/`.
- Assigned dependency replacement to a conditional library reviewer after the DAG review relied on React Flow behavior without an explicit external research owner. Recommendations now require the installed version and matching official public-API evidence. Evidence: `../../evals/simplicity-review/cases/graph-rendering-core/`.
- Added optional `CONTEXT.md` and `CODING_STANDARDS.md` discovery for reviews so repository language and conventions participate when available without making Matt Pocock skills a dependency. Evidence: `../../evals/simplicity-review/cases/compatibility-fallbacks/`.
- Made clean state ownership and non-duplication an acceptance condition after an algorithm review could otherwise label a local deletion simpler while moving copies, derivations, traversals, or coordination into callers. Evidence: `../../evals/simplicity-review/cases/graph-rendering-core/`.
- Formalized the counterfactual test-value standard after the Geoflow planning review found tautological, implementation-bound, and ineffective tests. Evidence: `../../evals/simplicity-review/cases/report-seams/`.
- Added a bounded consistency pass for repeated peers after user feedback identified drift in terminology, casing, module patterns, and testing patterns as a cross-cutting review concern. Evidence: `../../evals/simplicity-review/cases/status-consistency/`.
- Replaced repository-wide lens dispatch with a coverage map and semantic-core waves after the IOW API review searched 149 modules but returned a wholesale `KEEP` for alerting and monitoring without tracing either lifecycle. Prior audits now follow the fresh pass because the run anchored on an older audit that excluded those systems. Evidence: `../../evals/simplicity-review/cases/service-lifecycle-coverage/`.
