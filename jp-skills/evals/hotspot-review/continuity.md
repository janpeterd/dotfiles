# Hotspot review cases

User-requested entry point for the Anti-Slop wiki's complexity-report workflow. These are acceptance cases, not executed model trials.

- A report flags a large controller and its store: trace their shared lifecycle, preserve semantic authority, and provide concrete KEEP/repair/extraction alternatives without editing either file.
- A report names a removed symbol from an older revision: record the mismatch and inspect the current path before treating the score as a finding.
- Several flags describe one acceptance operation: group the causal review and account for each flag rather than inventing a separate module per warning.
- A request asks for a local pluralization fix without a hotspot investigation: ordinary implementation applies; this skill should remain inactive.

Validation for this addition covers frontmatter, relative links and the installed link. No model bakeoff was requested or run.
