# Frontend code pattern evals

These cases measure whether a skill improves React application structure, data boundaries, forms, typing, and visual consistency without imposing frontend conventions on unrelated work.

## Development order

1. Reduce a real frontend problem to the smallest fixture that preserves the decision.
2. State the user-visible problem and maintenance goal in the prompt.
3. Keep architectural expectations in the rubric, outside the candidate prompt.
4. Run the skill-absent arm before drafting an instruction.
5. Record each observed failure beside the instruction proposed to correct it.
6. Keep candidate synthesis separate from promotion bakeoffs.
7. Compare proposed, prior, and absent arms across at least two model families.

Deterministic checks cover behavior. The rubric and blinded review judge component boundaries, ownership, typing, and design quality.
