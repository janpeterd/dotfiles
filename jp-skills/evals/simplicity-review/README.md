# Simplicity review evals

These cases measure whether the reviewer removes incidental structure while defending complexity required by behavior, safety, or real variation.

Candidate prompts provide an implementation, its request, and runnable checks. They do not name the expected cuts. Rubrics judge whether every recommendation includes a smaller implementation and evidence that acceptance conditions remain intact.

Keep promotion bakeoffs small. Compare proposed, prior, and skill-absent arms on both cases across two model families before promotion.
